# UI/UX Prompt for Figma or a Design Agent

Create a polished UI/UX design system and set of high-fidelity mobile screens for the Ykay College app. The design should feel premium, calm, trustworthy, and modern, with a strong educational brand identity.

## Product Context
Ykay College is a school platform mobile app for students, parents, teachers, and administrators. The app should help users access school information, track learning progress, manage attendance and fees, and stay connected to school activity from their phone.

The design should reflect a mature product that is already structured around role-based experiences and should feel cohesive across all user journeys.

## Core Goals
Design a mobile experience that is:
- modern and premium,
- easy to navigate,
- highly readable,
- visually calm and trustworthy,
- aligned with the Ykay brand,
- and optimized for daily school use.

## Target Users
Create experiences for:
- Students
- Parents
- Teachers
- Administrators

Each role should have a distinct but consistent experience tailored to their needs.

## Visual Direction
Use a premium, educational, mobile-first aesthetic.

Design principles:
- clean and uncluttered layouts,
- strong hierarchy and readability,
- soft rounded corners and polished spacing,
- subtle depth through cards and shadows,
- calm, professional tone,
- modern UI with refined interactions,
- no clutter, no overly playful visuals, no corporate coldness.

## Brand Language
Maintain a strong Ykay identity through:
- deep navy and dark foundation tones,
- green accents for emphasis and success states,
- clean white or soft neutral surfaces,
- premium card-based layout language,
- strong contrast for readability,
- consistent component styling across all screens.

## Typography
Use a modern sans-serif system with clear hierarchy.
- bold headings for section titles,
- clean readable body text,
- strong labels for metrics and actions,
- polished spacing between content blocks.

## Layout and Interaction Style
The app should feel like a refined mobile product rather than a generic dashboard. Prioritize:
- one clear primary action per section,
- easy scanning of information,
- smooth and intuitive navigation,
- consistent spacing and component rhythm,
- clear states for loading, empty, error, and success,
- thoughtful use of motion and transitions where appropriate.

## Screens to Design
Create a full mobile experience including:

1. Splash / Launch
- premium brand introduction,
- clean centered branding,
- polished first impression.

2. Onboarding / Welcome
- short educational onboarding flow,
- clear value proposition,
- strong CTA for sign in or continue.

3. Authentication
- sign in screen,
- forgot password,
- password field styling,
- secure and modern form treatment.

4. Role-Based Entry
- student, parent, teacher, and admin entry experience,
- clear role distinction,
- premium cards and simple navigation.

5. Student Dashboard
- greeting and summary area,
- attendance overview,
- academic progress,
- quick actions for exams, reports, announcements, and profile.

6. Parent Dashboard
- child progress summary,
- attendance and fees overview,
- announcements and school updates,
- simple navigation to important actions.

7. Teacher Dashboard
- class overview,
- attendance tasks,
- gradebook access,
- student-related actions,
- announcements and messaging.

8. Admin Dashboard
- high-level school metrics,
- admissions and finance summary,
- alerts and recent activity,
- management-style cards.

9. Attendance Screen
- simple, readable attendance view,
- clear status indicators,
- intuitive calendar or list layout.

10. Report Cards Screen
- subject breakdown,
- grade summaries,
- polished result presentation.

11. Exams and Practice Screen
- exam list,
- progress states,
- start test CTAs,
- clear assessment navigation.

12. Exam Runner Screen
- question layout,
- answer selection,
- timer and progress,
- accessible and mobile-friendly experience.

13. Fees and Payment Screen
- fee summary,
- invoices or pending payments,
- pay action,
- clear financial status.

14. Payment Flow / Webview Screen
- secure payment experience,
- loading and success states,
- premium trust-building presentation.

15. Announcements / Notifications
- list of updates,
- unread indicators,
- clear grouping by importance or time.

16. Profile and Settings
- profile details,
- preferences,
- help/support links,
- sign out experience.

17. ID Card / Identity Screen
- premium student or staff identity card style,
- clean information layout.

18. Empty States
- no-data states for exams, fees, announcements, attendance, and notifications.

19. Error and Success States
- polished handling of failed actions,
- success confirmation states,
- reassuring visual feedback.

## Design System Components
Include a comprehensive design system with:
- color palette,
- typography scale,
- buttons,
- chips and tags,
- cards,
- form fields,
- tab bars,
- nav bars,
- stat cards,
- avatars,
- notification rows,
- progress indicators,
- empty states,
- loading states,
- and role-based UI patterns.

## Deliverables
Produce:
- a full mobile UI system,
- high-fidelity screen designs,
- consistent spacing and component language,
- clear visual hierarchy,
- polished interactions,
- accessible and modern mobile patterns.

## Output Style
Use a premium, modern, and highly polished visual language. Avoid generic SaaS UI. The result should feel like a refined education platform built for real users, not a template.
